## 定价需求MCC配置

工具可用性MCC  toolsAvailableMccConfig

```json
[{"desc":"定价调价","sceneType":"PRICING","toolCode":10}]
```



默认场景Id配置  sceneIdConfig

```json
[{"sceneId":8,"sceneType":"PRICING"}]
```



计算取值配置   pricingQlContextConfig

```json
[{"desc":"COM实价","needFen2Yuan":false,"qlVariableName":"comActualPrice","valueJsonPath":"$.comGoods.compActualPrice"},{"desc":"COM实价","needFen2Yuan":true,"qlVariableName":"mtBasePrice","valueJsonPath":"$.mtGoods.actualOldGoldenVip.basePrice"}]
```
